## 复现“有内容的界面”的技巧（重要）

作业按 cookie 作用域隔离：`src/lib/job-session.ts` 把 `agentscad-job-session` cookie 哈希成 `browserSessionId`。
本地 DB 里有 11 条历史作业，但新浏览器会话看不到，空状态会误导审查。
做法：`shasum -a 256` 算 `agentscad-job-session:v1:<uuid>`，临时 `update Job set browserSessionId=...`，用 Playwright `addCookies` 注入同一 token；截图后**逐行 diff 还原**并校验。
dev server 必须用 `bun run dev` 后台任务启动（子 shell `&` 会被 SIGHUP 杀掉）。

## 同日：17 项全部修复 + 回归验证

97 个文件改动。报告里新增「修复记录」「回归验证」「顺手挖出的两个故障」三节。

### 关键根因（不是表面现象）
- **右列裁切**：`Module` flow 模式带 `shrink-0`，三块 754px 挤 702px 容器。改 `min-h-0` + 列内 flex 分配（52% / flex-1 / flex-none），每块 body 自己滚。
- **E 键死键**：`setActiveTab('CODE')` 只改 Sheet 内部页签值，Sheet 本身关着。必须同时 `setShowDetails(true)`。
- **字号假声明**：`globals.css` 一条 unlayered 规则把所有 8–9.5px 强制改成 10px。先批量改写 57 处声明，再删规则，渲染才收敛到 5 档。

### BUG-A：Tailwind 把二进制读成类名（P0，整站打不开）
`@import "tailwindcss"` 的自动扫描读了 `.next-review`（未 gitignore）和 `db/dev.db`，把控制字符当类名，生成 `@media (m<0x05> :coarse)` 与 `.text-[var(<0x07>7…dim)]`，PostCSS 拒绝解析 → Build Error 覆盖层。坏 CSS 写回 sourcemap，下次编译再读回来，**自喂养**，看起来像随机故障。
修法：`@import "tailwindcss" source(none)` + 单条 `@source "../**/*.{ts,tsx}"`。
**教训**：`@source` 用目录（`"../"`）不如用 glob；Tailwind v4 的自动扫描会把任何未忽略的二进制当候选源。

### BUG-B：Bun `mock.module` 跨文件泄漏（P1）
`bun test` 同进程跑所有文件，API 路由测试把 `@/lib/tools/scad-renderer` 换成版本号为 `"test"` 的桩，WASM 测试排在后面就红。修法：该文件改子进程（`Bun.spawn` 跑 `bun test` 自身）。

### 测量方法学（两次假阴性，都差点写进结论）
1. **实心 signal = 0 曾是假阴性**：浏览器把 `color-mix()` 序列化成 `color(srgb …)`，旧检测器只认 `rgba()`，带 tint 的元素全被跳过。改 canvas 解析任意 CSS 颜色，并注入「实心橙 / 12% 橙」两个探针验证检测器能区分。**任何"计数为 0"的断言都要先证明检测器不是瞎的。**
2. **F 键曾被判死键**：`fit` 保持方向只调距离，相机本来就在 fit 距离时画面当然不变。先用滚轮 zoom 再按 F，放大/缩小都能精确回到同一基准帧。

### 最终数据（8 组合 = 4 视口 × 深浅）
裁切 0 / 实心 signal 0 / 对比度失败 0（逐文本节点 126·121·115·9）/ 字号 5 档 / 16 键全部可观测 / 硬编码 hex 0。`bun test` 542 pass 4 skip 0 fail。

### 新发现（12 项，性质从"画得糙"变成"画错了"）
- **N1 [P0] 陈旧判定自相矛盾**：`DimensionsModule` 的 `changed` 用 `values`（已构建值）比 `p.value`（schema 默认值）；`MainWorkspace.changes` 用 `paramDraft` 比 `p.value` 而 draft 初始 null。结果同一屏左边「1 parameter changed · Rebuild required」右边「No rebuild needed」。库里 8 个有 schema 的作业中 1 个不一致（edge_length built=30/schema=20），恰是默认选中那件。**陈旧必须只有一个写者：draft vs job.parameterValues。**
- **N2 [P1] 加载期假空态**：`/api/jobs?summary=true` 不含 `parameterSchema`/`parameterValues`/`validationResults`，但含 `stlPath`。点选后 1–2.5s 内尺寸与检验模块打印"Generate this part"，而同屏说 Ready to export。模块必须区分 pending 与 empty。
- **N3 [P1] 引擎名泄漏**：`ReadoutModule` 的 `Built by …`；`engineLabel()` 找不到模型时回退裸 `modelId`（`deepseek-v4-flash`）。违反 §26.8。
- **N4 [P1] 107 处 Tailwind 调色板类**（36 种，9 文件），**运行时探针证实工具类真的生效**（`text-emerald-400` → `lab(75.08 -60.73 19.41)`，`text-cyan-400` → `lab(76.60 -40.94 -29.62)`）。上一轮只扫 hex 是重大遗漏。ESLint 规则需从"禁 hex"扩到"禁调色板类名"。
- **N5 [P1] 首屏 3D 空窗 6.5s**（冷）/1–2.5s（热），而 `preview.png` 就在磁盘上未用作 poster frame。
- N6 移动端 sheet 页签无激活态（无 aria-selected/pressed，计算样式完全相同）；N7 10px 用在正文句子上；N8 内部语汇 `Target values are not measured geometry.`；N9 失败态强调层级倒置（待确认触发条件）；N10 AxesHelper 悬空 + 三原色；N11 浮板压零件栏 3511px²；N12 品牌副标题截断。
