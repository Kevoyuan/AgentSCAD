# 原创旋转卡口与多段路径实验

本例为锁止工具的独立两件实验，不代表单缸防脱已经实现。`quarter_turn_capture.scad` 是无旋转限位的对照，`quarter_turn_seated.scad` 增加侧向限位面。全部几何原创，没有引入第三方 CAD 源码。

销轴沿 Z，端部横梁尺寸8×2×2 mm；套板槽口8.8×2.8 mm。装配姿态横梁与槽口相差90°，横梁位于板上方、圆形头位于板下方。限位版在横梁两侧增加连接套板的实体面，阻挡原高度的直接转动；先沿+Z顶起1 mm后横梁可越过限位面，旋转-90°对准槽口，再向-Z移出至原坐标偏移-12 mm。

## 可复现的实际证据

```sh
bun scripts/eval/check-quarter-turn.ts
bun scripts/eval/check-quarter-turn.ts benchmarks/assembly/quarter_turn_seated.scad push
```

基线目录 `.agentscad/experiments/quarter-turn-1xnSOh/`：旋转后移出与反向装入PASS；直拔和45°错误角度FAIL。

限位版目录 `.agentscad/experiments/quarter-turn-9PzhLN/`：

- 先顶起、旋转、移出：116个显式累计位姿全部清楚，终点离开套板包围盒；反向完整路径也通过。
- 最大相邻原点位移约0.14943 mm，最大相邻方向变化5°；两个量都写入报告。不是连续扫掠体证明。
- 直拔：在-Z 1.05 mm采样位置失败。
- 不顶起就转：旋转10°时失败。
- 顶起后只转45°就拔：回落到+Z约0.70115 mm时失败。

报告保留全部变换矩阵、网格与路径哈希；源码、渲染参数、两个STL均保留。独立工具可对任一失败位姿重算销/套板交叠；若不存在报告所称的接触/交叠，则该失败断言被推翻。外部独立复核尚未执行。

## 工具能力与边界

`rigid-pose-path.ts` 接受完整位姿序列，检查每个右手刚体变换与相邻步长；拒绝空/静态路径、缩放、镜像、非有限值及越界步长。路径中每个姿态都从同一原始网格按累计变换定位，不在段之间重置。碰撞不确定为NOT_RUN；没有接触豁免。可选终点必须完全离开障碍物包围盒。

这里只证明指定刚体样点。未验证两个采样之间的碰撞、转动摩擦、手/工具空间、预紧和回弹、振动防松、材料/工艺公差及实物功能。限位几何不等于具有弹簧或自锁性。两件实验尚未嵌入单缸横销/前导向件，既有直线声明适配器仍拒绝转动和多段路径；产品也尚未自动执行此检查。后续需要设计适合单缸尺度与连接关系的保持件并完整回归，不能直接把本例PASS移植为整机证据。
