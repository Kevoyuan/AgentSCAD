## 能改变下一步决策的发现

### 1. 输出协议和错误反馈先于几何优化

**观测：** `8Kg6Vl/hinge-axial-45-0-response.json` 有 length 截断和 reasoning-only usage；旧路由把推理里的短代码作为可评候选。`wH9GDG/schema-diagnostics.json` 显示五个生成结果将 manufacturing.notes 写成字符串，一个缺少制造块；技能却把制造字段概括成 nullable string。

**修复：** [model-router.ts](../src/lib/tools/model-router.ts) 对显式设上限的请求拒绝 length 响应，保留 usage 错误证据。[provider-settings.ts](../src/lib/provider-settings.ts) 仅在显式请求时转发 token 上限和 reasoning_effort；普通路径默认行为保留。试验改用 none，避免思考耗尽预算。两个技能明确 `notes:string[]`，内嵌解析保留最多五个字段路径错误。

**边界：** 无推理模式解决本次交付协议问题，未证明更好的几何质量。拒绝截断不会退还已经发生的费用。

### 2. “范围声明 PASS”曾与“实际运动 FAIL”同时出现

**观测：** `cN1uDq` 原 judgment 在旋转碰撞后仍把 motion-range-deg 标 PASS；“可以拆开”还没有触发必须拆卸断言。只比较最大绝对角度也无法区分 0..90° 与 ±90°。

**修复：** [judge-assembly.ts](../scripts/eval/judge-assembly.ts) 仅在整个离散运动检查 PASS 时提供采样区间端点；否则区间覆盖 NOT_RUN。[extract-requirements.ts](../src/lib/requirements/extract-requirements.ts) 保留正负端点及“可以拆开”的肯定/否定，并把 fit ERROR 原样保留、向修复模型解释未测原因。公共 judge 同时以 identity 证据阻挡通过。

**免费重判：** `rejudged-assembly-lfwWki/report.json` 是当前判据下的原件重放，四个可入场候选实际重渲染，两个守卫拒绝候选 SKIP；`rejudged-assembly-LOejNx` 是此前保留版本。范围假通过消失，原件未被重新生成或手改。当前几何检查的碰撞分歧仍保留在报告中，不能说这些修复已经解决接触判定。

### 3. 声明帧、整机显示和零件几何可以各说各话

**观测：** `cN1uDq/hinge-axial-90-tight-1.scad` 的 frameA/frameB direction 均 `[0,0,1]`，但实际圆柱经 rotate([0,90,0]) 沿 X 构造。两个叶片都有孔，制造说明明确写销是未建模的采购件；声明只有两个叶片实例，没有销的采购实例或规格/BOM。

另一个版本 `hinge-axial-90-tight-0.scad` 的 all 分支把 moving leaf 额外转 90°，但 JSON 两个实例变换都是单位矩阵。现有 identity 检查仍 PASS。静态源码足以证实变换表达不一致；尚未执行整机与按清单重建模型的对称差测量，不能报其具体体积差。

**判断：** 两件、可导出、声明 revolute 不能证明有完整可工作的连接。沿错轴运动即使没有碰撞，也不是铰链。优先需要“导出→按 manifest 重装→与交付装配姿态一致”的门禁，以及从网格独立识别孔/轴、核对连接帧和全部生成/采购实例。不是先增加零件数量或更换 CAD 内核。

### 4. 表面三角相交不能直接当实体穿透

## 判据、状态和未执行项

当前真实模型结论为“未获得完整数字功能证据”，不是“模型完全不能做 CAD”。部分导出和拆卸子检查有正证据，其他地方有真实失败或工具不可测。

- PASS：仅限实际执行的对应子断言，例如 selector distinctness、一个版本的采样平移路径；不提升为整机通过。
- FAIL：已执行断言被具体反例否定，例如选择器未隔离、独立布尔检测到正体积重叠。
- ERROR：协议截断、schema 不合或工具无法完成所声明的测量；配合 ERROR 不是实测过盈。
- SKIP：修复守卫拒绝而没有进入新几何评估的候选。
- NOT_RUN：止挡两题、完整用户确认流程、连续扫掠、保持/实际自由度、制造和实物功能、独立隐藏集、人工盲评、用户验收。

`intent-preserved:PASS` 当前只检查有没有对应类型连接，代码已注明 declaration only；不是全量需求保真。`measured-part-identity:PASS` 当前也只覆盖选择器独立性和包围盒条件；不是身份/位置/功能的全面测量。这两项名义仍有误读风险，后续应拆成范围明确的断言。

不统计外部制造时间、材料成本或实物失败率，因为没有执行。两批六调用耗时约 113.37 / 124.84 秒，仅属该诊断脚本，不是浏览器交付延迟。没有使用此两题结果估计全产品成功率。

**已观察结果**：初稿含 assemble/disassemble 操作，但矩阵最后一行违反齐次变换格式，schema拒绝，未进行几何测量。修复稿纠正矩阵，提供两个生成件和全操作，但以5个粗疏位姿表示26 mm行程；现检查器对显式多位姿要求≤0.25 mm/5°，装拆均 ERROR（Pose gap exceeds declared sampling bounds）。这不是已测路径碰撞，也不能降要求变成PASS。理想运动在−45°报告三角面相交 FAIL；孔测量在−12 mm处不包围声明轴 ERROR，测量站受整体叶片长度影响，不能解读成实测孔径超差或无孔。重装超过15秒 NOT_RUN，不是已证位姿失配。模型自行写明缺正向轴向锁、轴向保持/磨损/打印条件未验证；物理/用户验收 NOT_RUN。没有完整功能通过。

**独立复核**：同目录 `independent-interior-audit.py` 为原创 Python 标准库，不调用产品BVH。读取保留二进制STL，核验长度/有限坐标/有向边，按顶点连接图计数：固定件2个分量，活动件1个，两个网格均无边关联异常。这说明两个 selector 文件并不等于两个完整单体；当前 identity PASS 只证明不同且位于范围内，不证明部件连通。
